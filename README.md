# Cybersecurity Incident & Threat Analysis using SQL

## Project Overview

This project analyzes cybersecurity incidents using SQL and MySQL. It explores different attack types, target industries, financial losses, affected users, security vulnerabilities, defense mechanisms, and incident resolution times.

The goal is to practise SQL queries and understand how data analysis can help identify cybersecurity trends and potential areas of concern.

## Objectives

- Analyze financial losses across different attack types.
- Identify industries with high average incident losses.
- Examine attack sources and affected users.
- Compare incident resolution times across vulnerabilities.
- Evaluate financial loss associated with different defense mechanisms.
- Analyze yearly changes in financial losses.
- Practise advanced SQL concepts for data analysis.

## Tools Used

- MySQL
- MySQL Workbench
- SQL

## Dataset

**Dataset:** Global Cybersecurity Threats (2015–2024)

**Source:** [Hugging Face Dataset](https://huggingface.co/datasets/Deshaune/Global-Cybersecurity-Threats-2015_2024)

The dataset contains information about cybersecurity incidents, including country, year, attack type, target industry, financial loss, affected users, attack source, vulnerability type, defense mechanism, and resolution time.

## SQL Concepts Practised

- SELECT and ORDER BY
- Aggregate functions: SUM(), AVG(), COUNT()
- GROUP BY and HAVING
- Subqueries
- Common Table Expressions (CTEs)
- Window functions: ROW_NUMBER() and LAG()
- JOIN operations
- Ranking and year-over-year analysis

## Business Questions

This project explores questions such as:

1. Which attack types cause the greatest total financial loss?
2. Which industries have the highest average financial loss?
3. Which attack sources are associated with the most affected users?
4. Which vulnerabilities have the longest average resolution time?
5. Which defense mechanisms have the lowest average financial loss?
6. How does financial loss change from year to year?
7. Which attack types have the highest financial loss within each year?
8. Which country–industry combinations have above-average financial losses?

## Project Workflow

1. Import the dataset into MySQL Workbench.
2. Inspect the table structure and column names.
3. Write SQL queries to answer business questions.
4. Aggregate and compare incident data.
5. Apply advanced SQL techniques for deeper analysis.
6. Interpret query results to identify useful patterns.

## Key Learnings

- Using SQL to analyze cybersecurity incident data.
- Summarizing financial losses and affected users.
- Comparing groups using aggregate functions.
- Applying subqueries, CTEs, and window functions.
- Translating business questions into SQL queries.

## Disclaimer

This is a learning and portfolio project based on a public dataset. The results represent patterns in the dataset and should not be interpreted as proof that a particular defense mechanism causes lower financial losses.
